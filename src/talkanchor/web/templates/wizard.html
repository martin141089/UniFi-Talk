Cloudflare Tunnel

Primäre IP-Quelle. Token-Scope: Account → Cloudflare Tunnel → Read.

⚠ Nicht der Tunnel-Token aus dem cloudflared tunnel run --token …-Befehl (der beginnt meist mit eyJ…)! Das hier ist ein separater API-Token, den du unter dash.cloudflare.com → dein Profil-Icon → My Profile → API Tokens → Create Token neu erstellst (kurzer String, ca. 40 Zeichen).

Fallback-IP-Quelle

Zweite, unabhängige Quelle. Muss mit Cloudflare übereinstimmen, bevor TalkAnchor handelt.
